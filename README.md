# Us the Village

A responsive, buildless website for a community initiative connecting families,
education, and career exploration. Built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` directly, or serve the repository with Python:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000. No package installation or build is needed.

## Files

- `index.html`: Home, About, Programs, and Contact sections.
- `styles.css`: Responsive layout, colors, typography, and reduced-motion support.
- `script.js`: Accessible mobile navigation and contextual program inquiry text.
- `assets/`: Original village illustration and favicon; no remote assets or fonts.

## Content to confirm before publication

The program descriptions are proposed areas of focus, not claims of scheduled or
operating services. Review their wording with the initiative. Contact uses the supplied public email address,
`s.seddighin@gmail.com`, via an email link. Visitors need a configured email app.
There is no submission form, backend, analytics, or personal-data storage.

## Manual review

- Check the layout at mobile, tablet, and desktop widths.
- On mobile, open Menu, follow a link, and check that the menu closes. Escape
  closes the menu and returns focus to its button.
- Tab through links and check visible focus and the Skip to content link.
- Follow each program link and check its context appears in Contact.
- Disable JavaScript: all content and navigation should remain available.

No hosting or deployment workflow is configured.
